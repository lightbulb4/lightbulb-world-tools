# Lightbulb World Tools

Lightbulb World Tools is a small collection of console-first Unity editor diagnostics and targeted repairs for VRChat worlds, without custom runtime components or a dedicated tool window.

## Install

Add the Lightbulb VPM listing to VRChat Creator Companion:

`https://lightbulb4.github.io/vpm/index.json`

Then add **Lightbulb World Tools** to a Unity 2022.3 project.

All commands are directly under **Tools > Lightbulb**. See the [package documentation](Packages/com.lightbulb.world-tools/README.md) for details.
